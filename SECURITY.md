# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting flow when it is enabled for this repository, or contact the repository owner privately.

Include the affected file, a minimal reproduction, impact, and any proposed mitigation. We will acknowledge reports within 7 days.

## Scope

Report vulnerabilities in repository automation, scripts, documentation that could cause unsafe commands to be run, or accidentally committed credentials. Local-model performance or quality regressions are not security reports.
